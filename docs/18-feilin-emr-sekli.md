# Əmr şəkli: oxu! gəl bura!

Azərbaycan dilində feilin əmr şəkli məstər şəkilçisini atıb yerinə müvafiq şəxs sonluğu əlavə etməklə alınır: oxumaq - oxu, oxusun, oxuyaq. Amma Fars dilində oxşar qrammatik quruluşu feilin [indiki zaman](https://farscabil.blogspot.com/2020/06/indiki-zaman.html) kökünün əvvəlinə "ب" [be] samiti əlavə etməklə düzəldilir:

<table><tbody><tr><td>vurmaq</td><td>zədən</td><td>زدن</td></tr><tr><td>Mən vurum/vuram</td><td>Mən bezənəm</td><td>من بزنم</td></tr><tr><td>Sən vur</td><td>To bezən</td><td>تو بزن</td></tr><tr><td>Sən vurasan</td><td>To bezəni</td><td>تو بزنی</td></tr><tr><td>O vursun/vura</td><td>U bezənəd</td><td>او بزند</td></tr><tr><td>Biz vuraq</td><td>Ma bezanim</td><td>ما بزنیم</td></tr><tr><td>Siz vurunuz/vurasınız</td><td>Şoma bezənid</td><td>شما بزنید</td></tr><tr><td>Onlar vursunlar/vuralar</td><td>Anha bezənənd</td><td>آنها بزنند</td></tr><tr><td>qayıtmaq</td><td>bərgəştən</td><td>برگشتن</td></tr><tr><td>qayıt</td><td>bərgərd</td><td>برگرد</td></tr><tr><td>qayıtma</td><td>bər nəgərd</td><td>برنگرد</td></tr></tbody></table>

Yuxarıdakı nümunələrə baxsaq görərik:

- Əmr şəklinin inkarını düzəltmək üçün "ب" [be] şəkilçisi "ن" [nə] ilə əvəz olunur.
- Düzəltmə feillərin əmr şəklini düzəltmək üçün feilə "ب" [be] əlavə etmək lazım deyil, sadəcə indiki zaman kökünü işlətmək kifayətdir.
- Düzəltmə feillərin əmr şəklinin inkarını düzəltmək üçün "ن" [nə] inkar əlaməti köklə şəkilçi arasına artırılır (bər+nə+gərd).

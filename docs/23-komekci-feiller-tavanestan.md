# Köməkçi feillər: توانستن [təvanestən]

Fars dilində "edə bilmək", "gedə bilmək", "deyə bilmək" kimi ifadələri qura bilmək üçün توانستن [təvanestən] feilindən istifadə edilir. توانستن [təvanestən] feili ingilis dilindən bizə tanış olan "can" köməkçi feilinə müvafiqdir. توانستن [təvanestən] sözünün mənası "bacarmaq"dır və feilin [indiki zaman](https://farsdili.az/indiki-zaman-1) kökü توان [təvan]-dır. Bu feilin işlənmə şəkli belədir: təvanestən + əmr şəklində olan əsas feil, əsas və köməkçi feil hər biri şəxsə görə dəyişir.

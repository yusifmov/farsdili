# Bölmə 45 — Bayəd — lazım, vacib: cavablar

*Fars dili: qrammatika və söz ehtiyatı* (Kitab 2) · [Bütün cavablar](/cavablar)

## 45.1 Mötərizədəki feili <span className="fa">باید</span> ilə yazın
1 <span className="fa">باید بخوابی</span> · 2 <span className="fa">باید بیاید</span> · 3 <span className="fa">باید ببینند</span> · 4 <span className="fa">باید صبر کنیم</span> · 5 <span className="fa">باید بنویسید</span> · 6 <span className="fa">باید باشم</span>

## 45.2 <span className="fa">نباید</span>, yoxsa <span className="fa">لازم نیست</span>?
1 <span className="fa">نباید</span> · 2 <span className="fa">لازم نیست</span> · 3 <span className="fa">نباید</span>

## 45.3 Sərnişinə qaydaları izah edin: <span className="fa">باید</span> və ya <span className="fa">نباید</span> ilə cümlə qurun
1. <span className="fa">باید پاسپورت (خود را) نشان بدهید.</span>
2. <span className="fa">باید اظهارنامهٔ گمرکی را پر کنید.</span>
3. <span className="fa">نباید سلاح بیاورید.</span>

## 45.4 Keçmişdə edilməmiş vəzifə: Farsca yazın
1. <span className="fa">هفتهٔ گذشته باید می‌آمدی.</span> *Həfte-ye qozəşte bayəd mi-amədi.*
2. <span className="fa">باید مدارک را می‌آوردیم.</span> *Bayəd mədarek ra mi-avərdim.*

## 45.5 Farsca yazın
1. <span className="fa">کجا باید صبر کنیم؟</span> *Koca bayəd səbr konim?*
2. <span className="fa">او باید در خانه باشد.</span> *U bayəd dər xane başəd.*

## 45.6 Bu həftə nə etməlisiniz?
Cavablar fərdidir. Nümunə: <span className="fa">این هفته باید به بانک بروم. باید کتابم را تمام کنم.</span>

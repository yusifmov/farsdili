# Bölmə 76 — Məqsəd: ta / bəra-ye inke + arzu şəkli: cavablar

*Fars dili: qrammatika və söz ehtiyatı* (Kitab 2) · [Bütün cavablar](/cavablar)

## 76.1 İki cümləni <span className="fa">تا</span> ilə birləşdirin
1. <span className="fa">به کتابخانه رفتم تا درس بخوانم.</span>
2. <span className="fa">زود بیدار شد تا به اتوبوس برسد.</span>
3. <span className="fa">به پلیس زنگ زدیم تا کمک کند.</span>
4. <span className="fa">پنجره را باز کردم تا هوای تازه بیاید.</span>
5. <span className="fa">آهسته رفتیم تا کسی ما را نبیند.</span>

## 76.2 Məqsəd, yoxsa səbəb? Mötərizədəki feili yazın
1 <span className="fa">نشویم</span> (məqsəd) · 2 <span className="fa">نمی‌دانستیم</span> (səbəb) · 3 <span className="fa">نداشتیم</span> (səbəb) · 4 <span className="fa">بیدار نشوند</span> (məqsəd)

## 76.3 <span className="fa">برای</span> + məsdər ilə yazın
1. <span className="fa">برای خریدن نان بیرون رفتم.</span>
2. <span className="fa">برای گرفتن گذرنامه به اداره رفت.</span>
3. <span className="fa">برای کار کردن به باکو آمدند.</span>
4. <span className="fa">برای بازرسی مسافران دو مرزبان آمدند.</span>

## 76.4 Farsca yazın
1. <span className="fa">در را ببند تا گربه بیرون نرود.</span>
2. <span className="fa">به او زنگ زدم که فردا بیاید.</span>
3. <span className="fa">مرزبان چمدان را باز کرد تا داخلش را ببیند.</span>
4. <span className="fa">آهسته رانندگی کن تا تصادف نشود.</span>

## 76.5 Fars dilini nə üçün öyrənirsiniz? <span className="fa">تا</span> ilə iki cümlə yazın
Cavablar fərdidir. Nümunə: <span className="fa">فارسی یاد می‌گیرم تا با مسافران ایرانی حرف بزنم. می‌خواهم به ایران بروم تا شهرهای تاریخی را ببینم.</span>

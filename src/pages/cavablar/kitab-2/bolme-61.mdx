# Bölmə 61 — Xeyli, besyar, ziyad, kəm, kəmi, xeyli həm: cavablar

*Fars dili: qrammatika və söz ehtiyatı* (Kitab 2) · [Bütün cavablar](/cavablar)

## 61.1 Düzgün sözü seçin
1 <span className="fa">خیلی</span> · 2 <span className="fa">زیاد</span> · 3 <span className="fa">کم</span> · 4 <span className="fa">کمی</span> · 5 <span className="fa">زیادی</span>

## 61.2 Cümləni gücləndirin: <span className="fa">خیلی</span> və ya <span className="fa">زیاد</span> artırın
1. <span className="fa">این خیابان خیلی شلوغ است.</span>
2. <span className="fa">او زیاد ورزش می‌کند.</span> (və ya <span className="fa">خیلی ورزش می‌کند</span>)
3. <span className="fa">مرزبان خیلی دقیق است.</span> (və ya <span className="fa">بسیار دقیق است</span>)

## 61.3 Suala <span className="fa">خیلی هم</span> və ya <span className="fa">چندان … نـ</span> ilə cavab verin
1 <span className="fa">خیلی هم خوشمزه بود.</span> · 2 <span className="fa">چندان سخت نیست.</span>

## 61.4 Farsca yazın
1. <span className="fa">کمی خسته‌ام.</span>
2. <span className="fa">او خیلی کم حرف می‌زند.</span>
3. <span className="fa">پول کافی نداریم.</span>
4. <span className="fa">این چمدان زیادی سنگین است.</span>
5. <span className="fa">این اتاق چندان بزرگ نیست.</span>

## 61.5 Bu gün haqqında iki cümlə yazın
Cavablar fərdidir. Nümunə: <span className="fa">امروز هوا خیلی سرد است. کمی خسته‌ام، چون دیروز زیاد کار کردم.</span>

## 61.6 Mətndə boşluqları doldurun: <span className="fa">خیلی</span>، <span className="fa">کم</span>، <span className="fa">کمی</span>، <span className="fa">زیادی</span>

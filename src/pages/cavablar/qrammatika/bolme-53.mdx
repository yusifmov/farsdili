# Bölmə 53 — Şəxssiz konstruksiyalar: mi-şəvəd, bayəd rəft: cavablar

*Fars dilinin qrammatikası* · [Bütün cavablar](/cavablar)

## 53.1 Cümləni şəxssiz quruluşla yenidən yazın
1. <span className="fa">باید فرم را پر کرد.</span>
2. <span className="fa">نباید اینجا ایستاد.</span>
3. <span className="fa">می‌شود از این راه رفت؟</span>
4. <span className="fa">نمی‌توان با این ماشین از مرز رد شد.</span> / <span className="fa">نمی‌شود … رد شد.</span>

## 53.2 Lövhə üçün qayda yazın: <span className="fa">باید</span>, <span className="fa">نباید</span> və ya <span className="fa">می‌توان</span> ilə
1. <span className="fa">اینجا نباید سیگار کشید.</span>
2. <span className="fa">باید پاسپورت نشان داد.</span>
3. <span className="fa">پول را می‌توان در بانک عوض کرد.</span>

## 53.3 <span className="fa">می‌شود</span> ilə icazə istəyin
1. <span className="fa">می‌شود اینجا بنشینم؟</span>
2. <span className="fa">می‌شود از تلفنتان استفاده کنم؟</span>
3. <span className="fa">می‌شود فردا بیایم؟</span>

## 53.4 Tərcümə edin
1. Nə etmək lazımdır?
2. Bu havada bayıra çıxmaq olmaz.
3. Bu pəncərədən dənizi görmək olar.

## 53.5 İş yerinizin (məktəbinizin) üç qaydasını yazın
Cavablar fərdidir. Nümunə: <span className="fa">سر کار نباید دیر آمد. باید لباس فرم پوشید. نمی‌شود با تلفن بازی کرد.</span>

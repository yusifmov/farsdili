# Bölmə 44 — Arzu şəkli — keçmiş: rəfte başəm: cavablar

*Fars dilinin qrammatikası* · [Bütün cavablar](/cavablar)

## 44.1 <span className="fa">خوردن</span> feilini keçmiş arzu şəklində təsrif edin
<span className="fa">خورده باشم</span> · <span className="fa">خورده باشی</span> · <span className="fa">خورده باشد</span> · <span className="fa">خورده باشیم</span> · <span className="fa">خورده باشید</span> · <span className="fa">خورده باشند</span>

## 44.2 Ehtimal bildirin: cümləni <span className="fa">شاید</span> ilə yenidən yazın
1. <span className="fa">شاید اتوبوس رسیده باشد.</span>
2. <span className="fa">شاید آنها خوابیده باشند.</span>
3. <span className="fa">شاید راننده مدارک را نیاورده باشد.</span>

## 44.3 Hansı forma düzgündür?
1 <span className="fa">بیاید</span> · 2 <span className="fa">خوابیده باشند</span> · 3 <span className="fa">خالی کرده باشید</span>

## 44.4 Dostunuz gəlməyib
Cavablar fərdidir. Nümunə: <span className="fa">شاید مریض شده باشد. شاید ساعت را فراموش کرده باشد. شاید در ترافیک مانده باشد.</span>

## 44.5 Farsca yazın
1. <span className="fa">شاید او پاسپورتش را گم کرده باشد.</span> *Şayəd u pasportəş ra qom kərde başəd.*
2. <span className="fa">امیدوارم نامه را خوانده باشی.</span> *Omidvarəm name ra xande başi.*
3. <span className="fa">تا ساعت پنج باید آماده باشید.</span> *Ta saʼət-e pənc bayəd amade başid.*

## 44.6 Cümləni öz fikrinizlə tamamlayın
Cavablar fərdidir. Nümunə: <span className="fa">امیدوارم امتحان را خوب داده باشم.</span> <span className="fa">تا آخر هفته باید کتاب را تمام کرده باشم.</span>

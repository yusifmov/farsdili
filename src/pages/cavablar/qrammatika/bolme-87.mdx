# Bölmə 87 — Səs dəyişmələri: -an → -un (nan → nun), əst → -e: cavablar

*Fars dilinin qrammatikası* · [Bütün cavablar](/cavablar)

## 87.1 Sözü danışıq dilində necə deyildiyi kimi yazın
1 <span className="fa">نون</span> *nun* · 2 <span className="fa">تهرون</span> *Tehrun* · 3 <span className="fa">کتابخونه</span> *ketabxune* · 4 <span className="fa">ارزون</span> *ərzun* · 5 <span className="fa">بادوم</span> *badum* · 6 <span className="fa">جوون</span> *cavun*

## 87.2 <span className="fa">است</span> formasını danışıq formasına çevirin
1. <span className="fa">این ماشین تمیزه.</span> *İn maşin təmize.*
2. <span className="fa">مرزبان کجاس؟</span> *Mərzban kocas?*
3. <span className="fa">همکارم تبریزیه.</span> *Həmkarəm təbriziye.*
4. <span className="fa">بچه خسته‌س.</span> *Bəççe xəstəs.*
5. <span className="fa">این خیابون شلوغه.</span> *İn xiyabun şoloğe.*

## 87.3 Danışıq dilindəki cümləni kitab dilində yazın
1. <span className="fa">باران می‌آید.</span>
2. <span className="fa">کدام خانه مال شما است؟</span>
3. <span className="fa">آنها در کتابخانه هستند.</span>
4. <span className="fa">چمدان‌ها روی میز است.</span>

## 87.4 Hansı sözdə *-an → -un* dəyişməsi olmur? Dairəyə alın
<span className="fa">امتحان</span>, <span className="fa">انسان</span>, <span className="fa">امکان</span>. Qalan sözlər dəyişir: *zemestun, mehmun, asemun*.

## 87.5 Danışıq dilində deyin və oxunuşunu yazın
1. *Nun ərzune.*
2. *Barun mi-yad.*
3. *Kodum xiyabun?*
4. *Una tu xunən.*

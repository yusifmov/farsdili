# Bölmə 72 — Səbəb və nəticə: çon, çunke, bəra-ye inke, be xater-e: cavablar

*Fars dilinin qrammatikası* · [Bütün cavablar](/cavablar)

## 72.1 İki cümləni <span className="fa">چون</span> ilə birləşdirin: səbəb cümləsi əvvəldə olsun
1. <span className="fa">چون گرسنه بودم، ساندویچ خریدم.</span>
2. <span className="fa">چون جاده بسته بود، کامیون‌ها منتظر ماندند.</span>
3. <span className="fa">چون او فارسی بلد است، مترجم شد.</span>
4. <span className="fa">چون مغازه بسته بود، چیزی نخریدیم.</span>

## 72.2 <span className="fa">چرا</span> sualına cavab verin: <span className="fa">برای اینکه</span> ilə
1. <span className="fa">برای اینکه هوا سرد است.</span>
2. <span className="fa">برای اینکه دوستم آنجاست.</span>
3. <span className="fa">برای اینکه اتوبوس نبود.</span>
4. <span className="fa">برای اینکه کنترل گمرکی بود.</span>

## 72.3 Boşluğu doldurun: <span className="fa">به خاطرِ، چون، بنابراین</span>
1 <span className="fa">به خاطرِ</span> · 2 <span className="fa">چون</span> · 3 <span className="fa">بنابراین</span> · 4 <span className="fa">به خاطرِ</span> · 5 <span className="fa">چون</span>

## 72.4 Farsca yazın
1. <span className="fa">نیامدم، چون (چونکه) مریض بودم.</span>
2. <span className="fa">به دلیل مه، مرز بسته شد.</span>
3. <span className="fa">هوا آنقدر گرم بود که بیرون نرفتیم.</span>
4. <span className="fa">راننده ویزا نداشت، بنابراین برگشت.</span>

## 72.5 Niyə fars dilini öyrənirsiniz? İki səbəb yazın
Cavablar fərdidir. Nümunə: <span className="fa">فارسی یاد می‌گیرم، چون در مرز کار می‌کنم. برای اینکه به شعر فارسی علاقه دارم.</span>

# Bölmə 68 — Ümumi suallar; aya: cavablar

*Fars dilinin qrammatikası* · [Bütün cavablar](/cavablar)

## 68.1 Cümləni rəsmi ümumi suala çevirin: <span className="fa">آیا</span> ilə yazın
1. <span className="fa">آیا شما فارسی بلدید؟</span>
2. <span className="fa">آیا هواپیما فرود آمد؟</span>
3. <span className="fa">آیا این خیابان به میدان می‌رسد؟</span>
4. <span className="fa">آیا مسافران بلیت دارند؟</span>
5. <span className="fa">آیا بانک ساعت هشت باز می‌شود؟</span>

## 68.2 Seçim sualı qurun: <span className="fa">یا</span> ilə
1. <span className="fa">امروز می‌آیی یا فردا؟</span>
2. <span className="fa">با تاکسی رفتید یا پیاده؟</span>
3. <span className="fa">برنج می‌خواهی یا نان؟</span>
4. <span className="fa">در هتل می‌مانی یا در خانهٔ دوستت؟</span>

## 68.3 Sərhəd-keçid məntəqəsində. Sualları farsca yazın
1. <span className="fa">(آیا) این ماشین مال شماست؟</span>
2. <span className="fa">(آیا) پول همراه دارید؟</span>
3. <span className="fa">(آیا) اولین بار است که به ایران می‌آیید؟</span>
4. <span className="fa">شما توریست هستید یا برای کار آمده‌اید؟</span>

## 68.4 Təəccüb bildirin: <span className="fa">مگر</span> ilə sual yazın
1. <span className="fa">مگر امروز نمی‌آیی؟</span>
2. <span className="fa">مگر راننده را نمی‌شناسی؟</span>
3. <span className="fa">مگر مغازه بسته است؟ ساعت هنوز پنج است.</span>

## 68.5 Yeni iş yoldaşınıza dörd ümumi sual yazın
Cavablar fərdidir. Nümunə: <span className="fa">متأهل هستید؟ بچه دارید؟ در این شهر زندگی می‌کنید؟ فارسی بلدید؟</span>

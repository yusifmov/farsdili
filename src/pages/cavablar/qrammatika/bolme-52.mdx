# Bölmə 52 — Məchul növ: şodən ilə: cavablar

*Fars dilinin qrammatikası* · [Bütün cavablar](/cavablar)

## 52.1 Cümləni məchul növə çevirin
1. <span className="fa">در باز شد.</span>
2. <span className="fa">این پل ساخته شد.</span>
3. <span className="fa">مدارک کنترل می‌شود.</span>
4. <span className="fa">کالاها ضبط شده است.</span>

## 52.2 <span className="fa">فرستادن</span> feilinin məchul formasını yazın ("o", tək)
<span className="fa">فرستاده می‌شود</span> · <span className="fa">فرستاده شد</span> · <span className="fa">فرستاده شده است</span> · <span className="fa">فرستاده خواهد شد</span>

## 52.3 Məchul cümləni danışıq dilinə uyğun fəal cümləyə çevirin (üçüncü şəxs cəm)
1. <span className="fa">در این مغازه نان می‌فروشند.</span>
2. <span className="fa">ماشینم را تعمیر کردند.</span>
3. <span className="fa">جاده را بسته‌اند.</span>

## 52.4 Farsca yazın (rəsmi üslub)
1. <span className="fa">مدارک مسافران کنترل شد.</span>
2. <span className="fa">مرز فردا باز خواهد شد.</span>
3. <span className="fa">این کتاب به (زبان) فارسی نوشته شده است.</span>
4. <span className="fa">به راننده اجازه داده نشد.</span>

## 52.5 Şəhərinizdə nə tikilib, nə tikilir?
Cavablar fərdidir. Nümunə: <span className="fa">در شهر ما یک پل جدید ساخته شده است. یک مدرسه ساخته می‌شود.</span>

## 52.6 Feilin məchul növü var?
1 <span className="fa">خریده شد</span> · 2 yoxdur · 3 <span className="fa">دیده شد</span> · 4 yoxdur · 5 <span className="fa">ساخته شد</span> · 6 yoxdur

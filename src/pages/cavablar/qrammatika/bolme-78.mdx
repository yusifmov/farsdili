# Bölmə 78 — Şərt 2: indiki zamana aid qeyri-real şərt (cavablar)

*Fars dilinin qrammatikası* · [Bütün cavablar](/cavablar)

## 78.1 Vəziyyətə baxın və qeyri-real şərt cümləsi yazın
1. <span className="fa">اگر وقت داشتم، ورزش می‌کردم.</span>
2. <span className="fa">اگر ماشین داشتیم، پیاده نمی‌رفتیم.</span>
3. <span className="fa">اگر او اینجا بود، به ما کمک می‌کرد.</span>
4. <span className="fa">اگر رانندگی بلد بودم، با اتوبوس نمی‌رفتم.</span>
5. <span className="fa">اگر هوا سرد نبود، بیرون می‌رفتیم.</span>

## 78.2 Mötərizədəki feili düzgün formada yazın
1 <span className="fa">داشتم</span> · 2 <span className="fa">می‌شناختم</span> · 3 <span className="fa">می‌رفتم</span> · 4 <span className="fa">نمی‌ماندند</span>

## 78.3 <span className="fa">کاش</span> ilə arzunuzu yazın
1. <span className="fa">کاش دوستم اینجا بود.</span>
2. <span className="fa">کاش امروز تعطیل بود.</span>
3. <span className="fa">کاش فارسی را خوب می‌دانستم.</span>
4. <span className="fa">کاش صف مرز این‌قدر طولانی نبود.</span>

## 78.4 Farsca yazın
1. <span className="fa">اگر جای تو بودم، این کار را نمی‌کردم.</span>
2. <span className="fa">اگر خانه بزرگ‌تر بود، مهمان‌ها پیش ما می‌ماندند.</span>
3. <span className="fa">اگر ویزا داشتم، فردا به ایران می‌رفتم.</span>
4. <span className="fa">کاش امروز کار نمی‌کردم.</span>

## 78.5 Tehranda yaşasaydınız, nə edərdiniz? İki cümlə yazın
Cavablar fərdidir. Nümunə: <span className="fa">اگر در تهران زندگی می‌کردم، هر روز فارسی حرف می‌زدم. جمعه‌ها به موزه‌ها می‌رفتم.</span>

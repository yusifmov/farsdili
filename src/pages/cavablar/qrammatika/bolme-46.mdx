# Bölmə 46 — Təvanestən — bacarmaq: cavablar

*Fars dilinin qrammatikası* · [Bütün cavablar](/cavablar)

## 46.1 Mötərizədəki feili <span className="fa">توانستن</span> ilə indiki zamanda yazın
1 <span className="fa">می‌توانی ببینی</span> · 2 <span className="fa">می‌تواند بنویسد</span> · 3 <span className="fa">می‌توانند بخوانند</span> · 4 <span className="fa">می‌توانیم بیاییم</span> · 5 <span className="fa">می‌توانید کمک کنید</span> · 6 <span className="fa">نمی‌توانم بخوابم</span>

## 46.2 Cümlələri keçmişə çevirin: "bacardım" və ya "bacarmadım"
1. <span className="fa">توانستیم بلیت بخریم.</span>
2. <span className="fa">نتوانستم بخوابم.</span>
3. <span className="fa">راننده نتوانست مدارک را پیدا کند.</span>

## 46.3 Nəzakətlə icazə və ya kömək istəyin
1. <span className="fa">می‌توانم اینجا سیگار بکشم؟</span>
2. <span className="fa">می‌توانید چمدان را بلند کنید؟</span> / <span className="fa">می‌توانید کمک کنید؟</span>
3. <span className="fa">می‌توانم تلفن بزنم؟</span>

## 46.4 <span className="fa">بلد بودن</span> ilə sual və cavab yazın
1. <span className="fa">— ترکی بلدی؟ — بله، بلدم.</span>
2. <span className="fa">— آنها راه را بلدند؟ — نه، بلد نیستند.</span>

## 46.5 Nə bacarırsınız, nə bacarmırsınız?
Cavablar fərdidir. Nümunə: <span className="fa">می‌توانم فارسی بخوانم. رانندگی بلدم. نمی‌توانم شنا کنم.</span>

## 46.6 Farsca yazın
1. <span className="fa">فردا نمی‌تونم بیام.</span> *Fərda nemi-tunəm biyam.*
2. <span className="fa">دیروز نتوانستم به شما زنگ بزنم.</span> *Diruz nətəvanestəm be şoma zəng bezənəm.*
3. <span className="fa">می‌توانم اینجا پول عوض کنم؟</span> *Mi-təvanəm inca pul əvəz konəm?*

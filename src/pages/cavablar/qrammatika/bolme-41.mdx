# Bölmə 41 — Gələcək zaman: xahəm rəft; danışıq dilində gələcəyin indiki zamanla ifadəsi: cavablar

*Fars dilinin qrammatikası* · [Bütün cavablar](/cavablar)

## 41.1 <span className="fa">نوشتن</span> feilini gələcək zamanda təsrif edin
<span className="fa">خواهم نوشت</span> · <span className="fa">خواهی نوشت</span> · <span className="fa">خواهد نوشت</span> · <span className="fa">خواهیم نوشت</span> · <span className="fa">خواهید نوشت</span> · <span className="fa">خواهند نوشت</span>

## 41.2 Cümlələri gələcək zamana çevirin
1. <span className="fa">هفتهٔ آینده او را خواهیم دید.</span>
2. <span className="fa">فردا کار خواهند کرد.</span>
3. <span className="fa">سال آینده در دانشگاه خواهم بود.</span>
4. <span className="fa">کامیون‌ها فردا خواهند رسید.</span>

## 41.3 Cümlələri inkar formasında yazın
1. <span className="fa">او فردا نخواهد آمد.</span>
2. <span className="fa">ما این خانه را نخواهیم خرید.</span>
3. <span className="fa">گمرک امروز باز نخواهد بود.</span>

## 41.4 Hansı cümlə "gedəcəyəm", hansı "getmək istəyirəm" deməkdir?
1. Sabah bazara gedəcəyəm.
2. Bazara getmək istəyirəm.
3. Onlar gələn il maşın alacaqlar.

## 41.5 Farsca yazın: əvvəlcə rəsmi, sonra danışıq üslubunda
| № | Rəsmi | Danışıq |
|---|---|---|
| 1 | <span className="fa">فردا باران خواهد آمد.</span> | <span className="fa">فردا بارون میاد.</span> *Fərda barun mi-yad.* |
| 2 | <span className="fa">هفتهٔ آینده به تبریز خواهیم رفت.</span> | <span className="fa">هفتهٔ بعد میریم تبریز.</span> *Həfte-ye bəʼd mi-rim Təbriz.* |

## 41.6 Gələn il nə edəcəksiniz?
Cavablar fərdidir. Nümunə: <span className="fa">سال آینده به ایران خواهم رفت.</span>

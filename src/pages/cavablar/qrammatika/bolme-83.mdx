# Bölmə 83 — Qoşa bağlayıcılar: həm … həm, nə … nə, ya … ya: cavablar

*Fars dilinin qrammatikası* · [Bütün cavablar](/cavablar)

## 83.1 İki cümləni mötərizədəki qoşa bağlayıcı ilə birləşdirin
1. <span className="fa">او هم انگلیسی بلد است هم فارسی.</span>
2. <span className="fa">نه ماشین داریم نه دوچرخه.</span>
3. <span className="fa">یا با قطار می‌رویم یا با اتوبوس.</span>
4. <span className="fa">چه باران بیاید چه نیاید، می‌رویم.</span>
5. <span className="fa">مسافر نه بلیت داشت نه پول.</span>

## 83.2 Boşluğu uyğun qoşa bağlayıcı ilə doldurun
1 <span className="fa">هم … هم</span> · 2 <span className="fa">نه … نه</span> · 3 <span className="fa">یا … یا</span> · 4 <span className="fa">نه تنها … بلکه</span> · 5 <span className="fa">چه … چه</span>

## 83.3 Farsca yazın
1. <span className="fa">این رستوران هم ارزان است هم خوشمزه.</span>
2. <span className="fa">نه زنگ زد نه نامه نوشت.</span>
3. <span className="fa">یا گذرنامه را نشان دهید یا کارت شناسایی را.</span>
4. <span className="fa">چه تابستان چه زمستان، آدم‌های زیادی به اینجا می‌آیند.</span>
5. <span className="fa">در کامیون نه میوه بود نه سبزی.</span>

## 83.4 Cümlələri azərbaycanca tərcümə edin
1. Təkcə sərhədçilər deyil, gömrük əməkdaşları da gəldi.
2. İstəsən də, istəməsən də, bu formu doldurmalısan.
3. O, nə işləyir, nə oxuyur.

## 83.5 Özünüz haqqında yazın: <span className="fa">هم … هم</span> və <span className="fa">نه … نه</span> ilə iki cümlə
Cavablar fərdidir. Nümunə: <span className="fa">من هم فارسی بلدم هم روسی. نه سیگار می‌کشم نه قهوه می‌خورم.</span>

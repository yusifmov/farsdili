# Bölmə 79 — Şərt 3 (qeyri-real keçmiş): cavablar

*Fars dilinin qrammatikası* · [Bütün cavablar](/cavablar)

## 79.1 Vəziyyətə baxın və keçmişə aid qeyri-real şərt cümləsi yazın
1. <span className="fa">اگر زود بیدار شده بودم، به کلاس دیر نمی‌رسیدم.</span>
2. <span className="fa">اگر نقشه داشتیم، گم نمی‌شدیم.</span>
3. <span className="fa">اگر بیمه خریده بود، پول زیادی نمی‌داد.</span>
4. <span className="fa">اگر به من گفته بودی، می‌آمدم.</span>
5. <span className="fa">اگر راننده ویزا داشت، از مرز رد می‌شد.</span>

## 79.2 Mötərizədəki feili uzaq keçmişdə yazın
1 <span className="fa">خریده بودیم</span> · 2 <span className="fa">دیده بودم</span> · 3 <span className="fa">داده بودی</span> · 4 <span className="fa">نیامده بود</span> · 5 <span className="fa">نگشته بود</span>

## 79.3 <span className="fa">کاش</span> ilə təəssüfünüzü yazın
1. <span className="fa">کاش گذرنامه‌ام را در خانه فراموش نکرده بودم.</span>
2. <span className="fa">کاش به جشن تولد دوستم رفته بودم.</span>
3. <span className="fa">کاش دیشب دیر نخوابیده بودم.</span>
4. <span className="fa">کاش برای امتحان خوب آماده شده بودم.</span>

## 79.4 Farsca yazın
1. <span className="fa">اگر می‌دانستم، منتظرت نمی‌ماندم.</span>
2. <span className="fa">باید بیشتر دقت می‌کردی.</span>
3. <span className="fa">اگر دیروز زنگ زده بودی، با تو می‌رفتم.</span>
4. <span className="fa">کاش آن خانه را نفروخته بودیم.</span>

## 79.5 Keçən il nəyi başqa cür edərdiniz? İki cümlə yazın
Cavablar fərdidir. Nümunə: <span className="fa">اگر پارسال بیشتر درس خوانده بودم، الان فارسی‌ام بهتر بود. کاش به سفر رفته بودم.</span>

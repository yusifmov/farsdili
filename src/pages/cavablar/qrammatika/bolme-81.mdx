# Bölmə 81 — Nida cümlələri: çe … !: cavablar

*Fars dilinin qrammatikası* · [Bütün cavablar](/cavablar)

## 81.1 Nida cümləsi yazın: <span className="fa">چه</span> + sifət
1 <span className="fa">چه جالب!</span> · 2 <span className="fa">چه زود!</span> · 3 <span className="fa">چه خوشمزه!</span> · 4 <span className="fa">چه طولانی!</span> (və ya <span className="fa">چه دور!</span>)

## 81.2 Cümləni <span className="fa">چه</span> + isim + sifət ilə nida cümləsinə çevirin
1 <span className="fa">چه شهر زیبایی!</span> · 2 <span className="fa">چه آدم خوبی!</span> · 3 <span className="fa">چه ماشین گرانی!</span> · 4 <span className="fa">چه باغ بزرگی!</span> · 5 <span className="fa">چه صف طولانی‌ای!</span>

## 81.3 Uyğun nida sözünü yazın: <span className="fa">آفرین، به به، خدا را شکر، ای وای، آخ</span>
1 <span className="fa">آفرین!</span> · 2 <span className="fa">ای وای!</span> · 3 <span className="fa">خدا را شکر!</span> · 4 <span className="fa">به به!</span> · 5 <span className="fa">آخ!</span>

## 81.4 Farsca yazın
1. <span className="fa">چه فرش قشنگی است!</span>
2. <span className="fa">چقدر شلوغ است!</span>
3. <span className="fa">چه کتاب جالبی است!</span>
4. <span className="fa">چه خوب که جاده باز است!</span>
5. <span className="fa">چقدر دیر آمدید!</span>

## 81.5 Bu gün sizi nə sevindirdi, nə təəccübləndirdi? Nida cümlələri ilə üç cümlə yazın
Cavablar fərdidir. Nümunə: <span className="fa">چه هوای خوبی بود! چه خوب که دوستم زنگ زد! چقدر کار داشتم!</span>

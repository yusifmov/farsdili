# Bölmə 77 — Şərt 1 (real): əgər + arzu şəkli / indiki zaman: cavablar

*Fars dilinin qrammatikası* · [Bütün cavablar](/cavablar)

## 77.1 Mötərizədəki feili arzu şəklində yazın
1 <span className="fa">باشد</span> · 2 <span className="fa">ببینی</span> · 3 <span className="fa">داشته باشیم</span> · 4 <span className="fa">حرکت کنی</span> · 5 <span className="fa">نیاید</span>

## 77.2 İki hissəni birləşdirib şərt cümləsi yazın
1. <span className="fa">اگر گرسنه‌ای، غذا بخور.</span>
2. <span className="fa">اگر گذرنامه نداشته باشید، نمی‌توانید رد شوید.</span>
3. <span className="fa">اگر وقت داری، به ما سر بزن.</span>
4. <span className="fa">اگر قطار دیر کند، با اتوبوس می‌رویم.</span>

## 77.3 Cümləni <span className="fa">وگرنه</span> ilə tamamlayın
Cavablar fərdidir. Nümunə: 1 <span className="fa">… وگرنه جریمه می‌شوی.</span> · 2 <span className="fa">… وگرنه صبح خسته‌ای.</span> · 3 <span className="fa">… وگرنه نمی‌توانید وارد شوید.</span>

## 77.4 Farsca yazın
1. <span className="fa">اگر وقت دارید، به خانهٔ ما بیایید.</span>
2. <span className="fa">اگر کامیون فردا بیاید (آمد)، آن را بازرسی می‌کنیم.</span>
3. <span className="fa">اگر عجله نکنیم، دیر می‌رسیم.</span>
4. <span className="fa">اگر گذرنامه ندارید، نمی‌توانید از مرز رد شوید.</span>
5. <span className="fa">اگر ممکن است، فردا بیایید.</span>

## 77.5 Bu həftə sonu hava yaxşı olsa, nə edəcəksiniz? İki cümlə yazın
Cavablar fərdidir. Nümunə: <span className="fa">اگر هوا خوب باشد، با خانواده‌ام به کوه می‌رویم. اگر وقت داشته باشم، به دوستم هم زنگ می‌زنم.</span>
